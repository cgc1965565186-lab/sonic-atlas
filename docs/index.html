The listening space

一块会呼吸的声音坐标。

地形并不随机舞动。低频聚拢成有重量的中心块群，中频形成连贯流场，高频只点亮边缘、波峰与空气粒子；自动画质会根据持续帧率调整精度，而不是频繁跳档。

Designed in layers

沉浸，也要能自己掌控。

画质、歌词、镜头和导出都可以按场景选择。系统“减少动态效果”会得到尊重；进入全屏后，也可以用一个按键把歌词完全留在画面之外。

ADAPTIVE TOPOGRAPHY01

画质跟着设备走，音乐不用让路。

自动模式观察持续帧率，低帧 10 秒后降档，稳定 20 秒才允许升档；也可锁定低、中、高任一档。

VISUAL EXPORT02

留下画面，不带走整首歌。

支持四种截图比例与 5、10、15 秒实时短片。Sonic Atlas 水印始终保留，也可追加自己的昵称或短句。

IMMERSIVE CONTROL03

按下 L，让歌词退出全屏。

隐藏的是歌词图层，不是歌词数据。截图和短片会遵循当前状态，留下只有地形、粒子、灯光与封面配色的纯视觉作品。

Adaptive chroma

八种基调，和无数首歌。

内置主题为 Demo 与手动控制提供稳定基线。真实歌曲则从封面生长出独有色彩，并让地形、雾、粒子和少量 HUD 强调色同步迁移。

Local by design

沉浸，不以隐私为代价。

本地音乐只引用原文件，不复制、不上传。完整路径只留在主进程的当前用户私有索引中；网易云登录凭据由系统安全存储加密，Renderer 无法读取 Cookie。

01 / LOCAL FILES
原文件一直留在原位置

界面只通过内部曲目 ID 访问音频、封面和歌词，不能读取任意文件路径。

02 / CREDENTIALS
macOS 安全存储保护登录状态

不可用时只保留本次会话，不降级为明文凭据文件。

03 / DIAGNOSTICS
诊断报告默认完成脱敏

不记录 Cookie、完整歌曲地址或本地完整路径，也不会在后台自动上传。

First run · macOS

被 macOS 拦住？先确认来源，再仅为此应用放行。

当前 DMG 是未签名测试构建，因此 Gatekeeper 可能阻止首次打开。安全提示不等于文件有害；同样，它也不该被忽略。

只在确认安装包来自本官网或 Sonic Atlas 的 GitHub Releases，且你信任其来源时继续。不要关闭 Gatekeeper，也不要使用终端命令移除隔离保护。

  1. 安装到“应用程序”打开 DMG，将 Sonic Atlas 拖入“应用程序”文件夹，然后推出该磁盘映像。
  2. 先正常尝试打开一次从“应用程序”启动 Sonic Atlas；若看到无法验证或未识别开发者提示，关闭提示即可。
  3. 仅为 Sonic Atlas 放行前往“系统设置 → 隐私与安全性”，在“安全性”区域点“仍要打开（Open Anyway）”，再确认“打开”。该按钮通常只在首次尝试后约一小时内出现。

受管理的 Mac 可能禁用此选项，请联系 IT 管理员；如果来源有任何不确定，请删除 DMG 并停止安装。查看 Apple 的官方安全说明
